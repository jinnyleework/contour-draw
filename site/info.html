get started

one engine and one skill for Claude Code: get the project, open the figures, then ask for your first one

    01get the projectoncethe repo is private, so your git must already reach it

    The skill works on the engine in this project, at ~/Playground/visualiser, so clone it there:

    shell
    git clone https://github.com/jinnyleework/contour-draw.git ~/Playground/visualiser

    It needs Node 18 or later, and nothing else: the engine is plain JavaScript modules with no dependencies.

    02open the figuresengineevery figure on one page that opens straight from disk

    shell
    cd ~/Playground/visualiser/engine
npm test
npm run build
open dist/actions.html

    Or browse them here, in the library: hover a figure to drive it, open it to turn it, retune its lines and export it.

    03draw a figuredraw-contourone object as stacked slices, answering the cursor

    Open Claude Code in the project and ask for a figure in plain words. The skill offers two or three concepts, draws the one you pick on the engine, checks it, looks at it and hands it over.

    shell
    cd ~/Playground/visualiser && claude
    first prompt
    /draw-contour a lighthouse whose beam sweeps as you move across it
