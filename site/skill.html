draw-contour: ask Claude Code for an object in plain words, and get back a figure drawn as stacked contour slices that answers the cursor, checked and looked at

    01installoncea project skill: it comes with the repo

    The skill lives in the project, at .claude/skills/draw-contour/, so Claude Code picks it up in the project folder with nothing to install. To use it from any folder, copy it to your own skills:

    shell
    cp -R ~/Playground/visualiser/.claude/skills/draw-contour ~/.claude/skills/

    either way it works on the engine at ~/Playground/visualiser/engine; if that folder is missing, it says so and stops

    02start2 ways inbring nothing, or an idea

    a/draw-contourAsks what the object is and what the cursor should do to it, then carries on as below.
    b/draw-contour a toaster that pops as you move up itOffers two or three concepts, one line each, and draws the one you pick. Every figure's sheet in the library has a prompt to start one in its vein: open a figure, then prompt · copy.

    03workflow7 stepswhat the skill does, in order; it stops for you at the concept

    00orientReads the engine's README and the one example figure nearest the idea: one that rises, slides, or turns.
    01conceptTwo or three, one line each: the object, which part moves and how, where the cursor drives it, what intensity changes, and its rest pose. You pick one.
    02scaffoldtools/new-figure.mjs writes a working figure from a template and registers it.
    03buildShapes as signed distance functions, cut along what moves. One file, about 80 lines; the engine, page and tools are never edited to make a figure work.
    04checktools/check.mjs: the shapes close inside their boxes, the cursor reaches both ends, intensity changes the picture, no NaN, frame size and speed. Then npm test.
    05looktools/still.mjs draws eight poses on one sheet: rest, halfway, full, low and high intensity, two turns and the split. Nothing is done until it is looked at.
    06hand overBuilds and publishes the engine's page, adds the figure to the intensity table and says what was checked and what was not.

    04toolsengine/toolsthe skill runs these for you; they work from a shell too, from engine/

    new-figure.mjs stampStarts a figure from a working template, and registers it (--remove undoes it).
    check.mjs [stamp]Checks a figure, or all of them: a FAIL stops you, a warn is for you to read.
    still.mjs stampOne PNG of eight poses: dist/still-stamp.png.
    build.mjsJoins the engine and every figure into dist/actions.html, one file that opens from disk.
    publish.mjsThe same page in the form the Artifact host wants: one file per module.

    run as: node tools/… · this site's library builds from the same figures (node site/build.mjs)

    05rulesSKILL.mdwhat every concept and figure keeps

    1one ideaOne action the cursor scrubs from rest to full, not two.
    2rest is a drawingNothing moves until the pointer arrives, so the rest pose is what most people see.
    3a place to drive itUp the figure, or across it, with a hint that says where.
    4no wordsIdentity comes from geometry, never lettering; the page's hint line is the only text.
    5one strokeNo colour, fill or shading: one ink in rule A's weights.
    6open means hollowA drawer, lid or hatch that opens shows its inside.
    7face upSlices are horizontal, so the face that matters lies flat.
    8height, not frontThe painter orders by height alone: parts that must read as nearer never overlap on the page.
